>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы классифицируют файлы WinDivert как инструменты повышенного риска или хакерские средства, после чего удаляют их и отправляют в карантин. Название обнаружения обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Исключение рекомендуется настроить аккуратно и правильно; если вы не уверены в своих действиях, лучше отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", включите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Его отключение способно помешать настройке и работе Secure DNS на компьютере

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/boldmanateeoven/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить

4. Извлеките архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для запуска вместе с системой: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - переключить режим обхода ресурсов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках показывается один из статусов:
    - `none` - проверка не применяется ни к каким IP
    - `loaded` - IP сопоставляется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** - заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - найти распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - проверить сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe (обход).  
Если процесс не появился, обратитесь к [#522](https://github.com/boldmanateeoven/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - С правами администратора откройте текстовым редактором файл `hosts` в созданном каталоге
  - Вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните изменения и проверьте соединение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Работа не гарантируется. При отсутствии результата используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/boldmanateeoven/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут утрачивать работоспособность со временем.**
> Стратегия способна работать определённый период, а затем перестать работать после обнаружения.
> Здесь собрано много разных стратегий обхода. Если существующие варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Испытайте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/boldmanateeoven/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y
- Удалите каталог zapret
- Возьмите свежую версию на [странице релизов](https://github.com/boldmanateeoven/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть "Разблокировать", нажмите её, затем "Применить" и "ОК"
- Распакуйте файлы в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если всё не работает, закройте программу через значок замка в панели задач и выберите другую стратегию
- После поиска рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> выберите нужную стратегию

### Игра или приложение не работает при включённом обходе

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. В противном случае фильтрация может повлиять на неожидаемые ресурсы.

### Античит сообщает о проблеме с WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя раньше работала.
- См. также [#251](https://github.com/boldmanateeoven/zapret-discord-youtube/discussions/251)

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её.
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ею.
- Если Discord не работает и в браузере, снова проверьте все стратегии: YouTube и Discord могут требовать разные варианты.
- См. также [#252](https://github.com/boldmanateeoven/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/boldmanateeoven/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/boldmanateeoven/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/boldmanateeoven/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
